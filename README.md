# Real-Time Chat Application

A full-stack real-time chat application that allows users to communicate instantly with a modern and responsive user interface. The app includes secure authentication, live messaging, online user tracking, unseen message notifications, and profile management.

## Features

* User Signup & Login Authentication
* Real-Time Messaging with Socket.IO
* Online/Offline User Status
* Unseen Message Notifications
* Profile Update Functionality
* Responsive Modern UI
* Secure Cookie-Based Authentication
* Instant Message Delivery
* Protected Routes for Authorized Users

## Tech Stack

### Frontend

* React.js
* React Router DOM
* Tailwind CSS
* Axios
* React Hot Toast
* Socket.IO Client

### Backend

* Node.js
* Express.js
* MongoDB
* Socket.IO
* JWT Authentication
* Cookie-Based Sessions

## Functionality

* Users can create accounts and log in securely.
* Authenticated users can chat with other users in real time.
* Messages are delivered instantly using WebSockets.
* Online users are tracked dynamically.
* Unseen messages are counted and updated automatically.
* Users can edit and manage their profiles.

## Purpose

This project was built to practice and demonstrate full-stack development skills including authentication, real-time communication, REST APIs, state management, and socket integration.
